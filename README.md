CORAL BAY HEAT is an original open-world crime game that runs in a desktop browser from static files — no network requests, keyboard and mouse controls. Play as Dario Venn in a 7x6 coastal city: steal and drive six vehicle models, dodge or fight through a 0–5 wanted system with police pursuit, work a five-mission story chain, run taxi fares, hunt 12 collectibles, and spend your take in shops. Day/night cycle, traffic and pedestrian AI, WebAudio sound, and a versioned local save. All-original IP; nothing from Rockstar or GTA.

## Run it

Serve the `game/` folder with any static file server and open it in a desktop browser, e.g.:

```sh
node serve.ts
```

then open the local address it prints. Or open `game/index.html` directly in a browser.

Controls: WASD/arrows to move and drive, E to enter/exit vehicles, F to fight, Shift to sprint.
